# DSH Launcher 安装说明

这是一个**托盘启动器**，用来一键打开本地 DeepSeek Harness：启动器负责把
`dsh web` 服务跑起来，并在它自己的窗口里显示界面。

- 常驻系统托盘，**启动后没有窗口**，这是正常的
- 不影响你平时用的浏览器：没有标签页、不进历史记录、不共用 cookie
- 关掉窗口只是隐藏，服务继续跑；真正退出要走托盘菜单的 **Quit**

---

## 一、开始之前

你需要两样东西，都是一次性的：

| 需要 | 怎么来 |
|---|---|
| **Node.js** | `setup.bat` 会自动装；装不上就去 https://nodejs.org 下 LTS 版 |
| **@deepseek-ai/dsh** | `setup.bat` 会自动装 |

> **不需要 pnpm，也不需要额外的依赖包。** 只要全局装了 dsh，第一次启动时它会自己
> 把 profile 需要的几个配置文件建好。（这一点我实测验证过：全新的 DSH 目录下
> `dsh web` 能直接启动成功。）

**唯一需要你自己准备的是 DEEPSEEK API Key。** 第一次打开界面时 DSH 会引导你填写。

---

## 二、安装（推荐：跑脚本）

**双击 `setup.bat`**，它会依次：

1. 检查 Node.js，没有就用 winget 自动安装
2. 检查 npm
3. 检查 `@deepseek-ai/dsh`，没有就 `npm install -g @deepseek-ai/dsh`
4. 验证 `dsh --version` 能正常输出
5. 告诉你 `DSH Launcher.exe` 的确切路径

**重复运行是安全的**——已经装好的部分会被检测到并跳过。

### 如果 npm 装不上（网络问题）

脚本支持指定镜像源。在文件夹里按住 `Shift` 右键 →「在此处打开 PowerShell 窗口」，然后：

```powershell
.\setup.bat https://registry.npmmirror.com
```

### 如果报权限错误（EPERM / permission denied）

用**管理员身份**打开命令提示符，再跑一次 `setup.bat`。Windows 上全局安装有时需要提权。

### 手动安装（不想跑脚本的话）

```powershell
# 1. 装 Node.js：去 https://nodejs.org 下 LTS 版安装包，一路下一步
# 2. 装 dsh：
npm install -g @deepseek-ai/dsh
# 3. 验证：
dsh --version
```

---

## 三、启动

**双击 `win-unpacked\DSH Launcher.exe`。**

启动后**没有窗口**。请看**任务栏右下角的托盘区**找它的图标：

- 如果没看到，点托盘区那个 `^` 展开箭头
- **左键单击图标** → 打开 DeepSeek Harness
- **右键单击图标** → 菜单（打开 / 重启服务 / 诊断 / 检查更新 / 退出等）

首次打开会经历：小等待窗（"Starting DeepSeek Harness"）→ 然后界面出现，
**不需要登录**（认证由启动器自动完成）。

第一次可能需要等十几秒到一分钟，因为 DSH 要初始化。之后就是秒开。

## 四、常见问题

### 双击后什么都没发生？

正常现象——它是托盘程序。去任务栏右下角找图标，可能被折叠在 `^` 里。

### 提示"Windows 已保护你的电脑"

这个程序**没有代码签名证书**，所以 Windows SmartScreen 会拦截。点
**「更多信息」→「仍要运行」** 即可。这是未签名应用的必然代价，不是文件损坏。

### 启动就闪退 / 提示文件被阻止

从网上下载的文件会被 Windows 打上"来自 Internet"的标记。在本文件夹里打开
PowerShell，执行一次：

```powershell
Get-ChildItem -Recurse | Unblock-File
```

然后再启动。

### 界面提示 "Could not authenticate this window"

托盘右键 → **Restart service**，让 DSH 重新写一份会话记录，然后再打开界面。

### 界面提示 "Port 3080 is already in use"

3080 端口被别的程序占了。两个办法：

1. 关掉占用 3080 的程序
2. 改启动器端口：托盘右键 →「Open data folder」，编辑 `launcher-config.json`，
   把 `"port": 3080` 改成别的（比如 `3088`），保存后重启启动器

### 提示 "The dsh CLI was not found"

`setup.bat` 那一步没成功。手动跑一遍：

```powershell
npm install -g @deepseek-ai/dsh
```

### 想看看到底出了什么问题

托盘右键 → **Diagnostics...**，里面有服务状态、版本、路径，以及捕获的输出
（已自动隐藏敏感 token）。

## 五、安全须知

- **不要把自己机器上的 `~/.dsh/.credentials.yaml` 拷给别人。** 里面有你的 API Key
  引用和本机会话签名密钥，等于把你的账号和登录态交出去。
- 启动器产物本身**不含任何凭据**，也不含分享者的机器路径。每个人的 API Key 都是
  自己填的。
- 启动器**不会修改** `~/.dsh` 里的任何配置文件（DSH 是热加载配置的，两边同时写会
  互相覆盖）。它自己的设置存在 `%APPDATA%\dsh-desktop-launcher\`。

## 六、要不要用这个，还是用官方桌面端？

| | 本启动器 | 官方桌面端 |
|---|---|---|
| 前置要求 | 需要自己装 Node + dsh | 下载安装包直接装，**内置 Node/pnpm/Python** |
| 体积 | 约 368 MB（解压后） | 安装包更小，不用额外装环境 |
| 托盘图标 | ✅ 有 | ❌ 没有 |
| 自动更新 | 手动点（正确识别预发布版本） | ✅ 完整签名更新通道 |
| 代码签名 | ❌ 无（会触发 SmartScreen） | ✅ 有 |

**结论**：如果你已经在用 dsh 命令行，这个启动器是"补一个托盘 + 一键打开"的轻量方案；
如果你从没配过 dsh 环境，官方桌面端更省事。

官方桌面端说明：
https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.zh.md
